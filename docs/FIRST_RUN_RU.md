# Первый запуск tg-agents (русская инструкция)

## Что нужно заранее
- Переменные окружения (в `.env`): `ADMIN_PASSWORD`, `TELETHON_API_ID`, `TELETHON_API_HASH`, `GEMINI_API_KEY` (для генерации; можно пустым, будет заглушка).
- Docker Desktop/Engine установлен.

## Запуск сервисов
```bash
docker compose up --build --detach
# Проверка
docker compose ps
docker compose logs --tail=50 api
```

## Шаги в веб-интерфейсе
1. **Создайте проект.** Введите название, ниша по умолчанию — футбол.
2. **Подключите Telegram по QR.** На вкладке Telegram нажмите «Получить QR», отсканируйте в Telegram → Настройки → Устройства. Если запросят, введите пароль 2FA.
3. **Найдите каналы.** Нажмите «Найти мои каналы», выберите нужные и импортируйте.
4. **Обновите RSS сейчас.** Кнопка «Проверить RSS сейчас» на Старт/Источники.
5. **Сформируйте план на сегодня.** Нажмите «Сформировать план на сегодня» (на Старт).
6. **Предпросмотр и публикация.** Сгенерируйте превью, проверьте текст, затем «Опубликовать следующий».
7. **Включите автопубликацию и проверьте воркер.** В статус-панели убедитесь, что воркер онлайн; переключите автопубликацию в «Вкл».
8. **Синхронизируйте премиум-эмодзи.** В настройках нажмите «Синхронизировать», выберите эмодзи — он будет добавлен в начале постов.
9. **Включите веб-поиск (опционально).** Тумблер «Gemini Web Search»; учтите возможные квоты и стоимость запроса Google.
10. **Включите прогнозы и время.** Задайте время прогноза (МСК) и количество матчей, чтобы ежедневно выходил пост «Прогнозы».

## Частые проблемы и решения
- **Воркер офлайн.** Проверьте `docker compose logs worker`; перезапустите контейнер; убедитесь, что в статус-панели heartbeat обновляется.
- **Каналы не обнаружены.** Убедитесь, что подключены как администратор каналов; обновите вход по QR; попробуйте ввести Chat ID вручную.
- **Новости не подгружаются.** Проверьте URL RSS, нажмите «Проверить RSS сейчас», посмотрите логи `docker compose logs worker` на ошибки сетевого доступа.
- **Gemini вернул английский текст.** Включите веб-поиск, повторите генерацию; модель автоматически перегенерирует на русском, но при лимитах может дать заглушку.
- **Премиум-эмодзи не отображается.** Убедитесь, что выбранный эмодзи синхронизирован; alt должен быть ровно один символ — выбирайте из списка синка, не вводите вручную.
